# Handheld_Hacker
Handheld Hacking Project Goal: Create an open source Flipper Zero equivalent with Wi-Fi, BLE5.0, Sub-GHz RF, 125kHz RFID, 13.56MHz NFC, IR TX/RX, RTC, MicroSD card, USB HID Hijacking capabilities. Also allows for GPIO expansion over I2C, UART, or SPI which is settings configurable. 

Currently available:
- Wi-Fi (ESP32-S3)
- Bluetooth Classic (ESP32-S3)
- 125kHz RFID (RDM6300)
- 13.56MHz NFC (PN532)

In Progress:
- Sub-GHz RF (CC1101)
- USB HID Hijacking (USB-C Port; doubles as charging port)

For Later:
- IR TX/RX (TSOP1838 + Transistor-driven 38kHz IR LED)
- RTC Integration (DS3231)

- GPIO expansion (UART/I2C/SPI, 3.3V, GND)
